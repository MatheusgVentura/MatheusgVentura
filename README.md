## 🚀 Projetos em destaque

### 🔐 [WebSecLab](https://github.com/MatheusgVentura/WebSecLab)
Laboratório open source em **Python/Django** que demonstra na prática as **10 categorias do OWASP Top 10**, com cada cenário em modo **vulnerável** e **seguro**. Permite comparar a exploração controlada de falhas com suas respectivas correções, com login, controle de acesso, banco de dados e Docker — tudo documentado no README para reprodução.
`Python` · `Django` · `OWASP Top 10` · `Docker`

### 🔑 [secure-auth-api](https://github.com/MatheusgVentura/secure-auth-api)
API REST de **autenticação segura** com **Python, Django REST Framework e JWT**: cadastro de usuários, login, controle de permissões e boas práticas de segurança aplicadas.
`Python` · `Django REST` · `JWT` · `RBAC`

### 🤖 [chatbot-scouts-security-core](https://github.com/MatheusgVentura/chatbot-scouts-security-core)
Núcleo de **segurança e IAM** do projeto institucional **IDP × União dos Escoteiros do Brasil**: fluxo centralizado de autenticação com **Supabase Auth**, validação de tokens **Bearer/JWT**, refresh token e **RBAC** para os perfis Escoteiro e Gestor.
`JavaScript` · `n8n` · `Supabase Auth` · `JWT/RBAC`

### 🚩 [Projeto_Cyberseguranca](https://github.com/MatheusgVentura/Projeto_Cyberseguranca)
Estudos e laboratórios de cibersegurança — exploração web, análise e write-ups com perspectiva ofensiva aplicada à defesa.
